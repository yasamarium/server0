Introduction

Every day, people throw waste like plastic, paper, food, and metal in the same dustbin. Because of this, everything gets mixed up, and it becomes very hard to recycle. It also makes our surroundings dirty and causes pollution.

To solve this problem, our team made a simple project called AI Waste Separator. This is a smart dustbin that can automatically separate waste into different bins — like plastic, metal, paper, and organic (food) waste. It saves time, keeps us safe from touching garbage, and helps to recycle waste easily.

How It Works

1

Detection

Waste is dropped inside the dustbin and IR sensor detects it

2

Metal Check

Metal sensor checks if the item is metal

3

Moisture Analysis

Moisture sensor checks for wet/dry waste

4

Smart Sorting

Arduino processes data and opens the right bin

5

Completion

Waste falls into correct compartment and flap closes

Materials Used

Material Use
Arduino board Controls the system
IR sensor Detects when waste is dropped
Metal sensor Checks if the item is metal
Moisture sensor Checks wet or dry waste
Servo motor Moves the flap to correct bin
Power supply To run the system
LCD screen To show waste type
Plastic/Cardboard box Dustbin body
